Forex Backtester

Market Data

Storage Model

Historical candles are stored centrally in Cloudflare D1 so parameter experiments reuse the same data instead of repeatedly downloading from OANDA.

The design is instrument-sharded: one instrument database can hold multiple native granularities.

Candle Shape

{
  time,
  volume,
  bid: { open, high, low, close },
  ask: { open, high, low, close },
  mid: { open, high, low, close }
}

Strategy calculations normally use MID. Execution uses BID / ASK.

What Is Proven Today

EUR/USD is the proven end-to-end research dataset. Native M1 and M5 history are available for the backtester, including the accepted M5-strategy/M1-execution experiment path.

The engine has metadata entries for additional FX instruments, but engine metadata is not the same thing as having fully loaded/validated D1 history. Treat EUR/USD as the known-good data product until another instrument is imported and regression-tested.

Candle Reader

src/data/candle-reader.js reads one exact stored instrument/granularity/date window using keyset paging. The research experiment loads strategy and execution datasets once, then reuses them across every parameter combination.

If strategy and execution timeframes are the same, the service reuses the same candle array rather than loading twice.

Timeframe Reality

The fixed-timeframe parser understands S/M/H durations, but a requested timeframe must actually exist in D1. Typing M15 does not cause the candle reader to aggregate M1 data automatically.

This explicit model avoids accidental differences between native broker candles and locally aggregated candles.

Account Currency Note

For EUR/USD with a USD account, quote-to-account conversion is 1. If account currency differs from quote currency, Human Backtesting V1 requires an explicit fixed quoteToAccountRate. Dynamic historical currency conversion is not yet implemented.
