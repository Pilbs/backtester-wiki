ORB Strategy

Its Role in the Project

ORB is the first real strategy, a regression case and a research example. It is not the product architecture. The generic engine does not know what an opening range or breakout is.

Current Strategy Structure

src/strategies/orb/
  opening-range.js
  daily-opening-range.js
  breakout-detector.js
  orb-strategy.js
  orb-definition.js

The runtime constructs/freezes the daily opening range and emits a generic trade intent on the first eligible breakout. The definition describes the parameters that research may configure.

ORB Parameters

startHour
durationMinutes
startMinute
timeZone
stopLossPips
takeProfitPips

These can be defaults or sweep dimensions. A different strategy will have a different parameter definition while still using the same research engine.

How to Research ORB Today

Edit src/experiments/orb-sweep.js, then run:

npm run research:orb

The script currently contains the market/date/timeframe assumptions, account/risk assumptions, execution policy, normal ORB config and parameter grid.

The controlled smaller acceptance experiment can be run with:

npm run research:orb:smoke

Human Backtesting V1 Acceptance Run

The accepted smoke experiment used EUR/USD, M5 strategy candles and M1 execution candles over 1 June to 1 September 2026. It tested six SL/TP combinations against one dataset load.

All six runs completed. The strongest configuration in that limited acceptance window was 10-pip stop / 20-pip target: 62 trades, +190 pips, +20.1% account return, profit factor 1.54 and 7.18% max drawdown under the chosen test account assumptions.

This is an engine/research acceptance result, not a claim that 10/20 is an optimal production strategy. Monthly performance varied, which is exactly why deeper robustness research is the product goal.

Trade Diagnostics

The final acceptance pass also proved the causal MFE/MAE diagnostic fix. Intrabar entry and exit candles no longer leak unknowable pre-entry/post-exit movement into excursion figures. Compact experiment results retain rejection reason counts such as MAX_MARGIN_USAGE.

What Changes Next

ORB should stop needing its own human-facing experiment script. Research Platform V1 will make it selectable as strategy: "orb" from one generic config/runner, then from the browser UI.
