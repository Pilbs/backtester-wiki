ORB Strategy

Current Implementation

ORB is now a complete strategy implementation under src/strategies/orb/:

opening-range.js
daily-opening-range.js
breakout-detector.js
orb-strategy.js

The generic engine does not know what an opening range or breakout is.

Opening Range

The range tracks the highest MID high and lowest MID low during the configured session, then freezes once the session is complete. daily-opening-range.js resets the state using the strategy timezone rather than UTC midnight.

Breakout Detection

After the range is complete, the breakout detector identifies the first break above or below the frozen range. If a candle spans both sides, the ORB strategy currently declines to issue an entry for that ambiguous event.

Trade Intent

The strategy converts a breakout into the same generic contract used by any future strategy:

{
  action: "ENTER",
  side: "LONG",
  stopLoss: { type: "PIPS", value: stopLossPips },
  takeProfit: { type: "PIPS", value: takeProfitPips },
  metadata: { strategy: "ORB", ... }
}

ORB configuration still uses convenient values such as stopLossPips and takeProfitPips; the output contract presented to the execution engine is generic.

Real D1 Regression Run

The retained integration test runs ORB against EUR/USD M5 data for August 2026 using an 08:15 New York, 60-minute opening range with a 10-pip stop and 20-pip target.

The known regression result is 17 trades for the full 1 August to 1 September window. This gives us a stable reference point while the surrounding engine evolves.

Why ORB Exists Here

ORB is the first real strategy and a useful regression case, but the product is not intended to become an ORB-only backtester. It proves that a stateful, timezone-aware strategy can plug into the generic engine and produce executable intents.
