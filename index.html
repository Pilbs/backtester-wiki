The backtester is now the foundation. The next work is about making that foundation easy to use rather than endlessly adding engine features.

What Human Backtesting V1 Means

The engine now supports multiple simultaneous trades, HEDGING/NETTING, market/limit/stop/stop-limit orders, account equity and margin, risk-based sizing, drawdown controls, commissions/slippage, causal OHLC handling, multi-parameter sweeps, one dataset load per experiment, structured JSON results, yearly/monthly summaries and causal MFE/MAE diagnostics.

Common indicator helpers such as SMA, EMA, RMA, ATR and RSI also exist so manually ported strategies do not need to reinvent basic calculations.

How You Use It Today

For ORB, edit src/experiments/orb-sweep.js in the main backtester repository and run npm run research:orb. That file currently acts as the research form: market, account, execution assumptions, strategy defaults and parameter grid.

For a new strategy, manually port its rules into JavaScript, give it a strategy definition describing its configurable parameters, add a deterministic test, then run a small real-data experiment.

See Research & Experiments for the current config options and Strategy Development for the strategy contract.

What We Are Not Building

  • Not a TradingView replacement.
  • Not a visual strategy designer.
  • Not a broker or live execution platform.
  • Not an AI-first product where the model calculates P&L itself.

The strategy can continue to originate in TradingView. The research platform exists to test it more systematically and over deeper controlled history.

Next Milestone

Research Platform V1 starts with usability: one generic research.config.js, a strategy registry, discoverable account/execution options and a generic npm run research. After that works comfortably, the same configuration model becomes a minimal browser UI.
