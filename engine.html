Forex Backtester

Backtest Engine

Backtest Service

src/backtest/backtest-service.js is the main application-level entry point. A backtest job supplies instrument, strategy timeframe, execution timeframe, date range and a strategy instance.

runBacktestJob({
  instrument: "EUR_USD",
  strategyTimeframe: "M5",
  executionTimeframe: "M1",
  from,
  to,
  strategy
})

The service loads the two candle series, resolves instrument metadata such as pip size, runs the engine and returns configuration, data counts, signals, trades and summary metrics.

Strategy vs Execution Timeframe

The engine now separates the timeframe used to make decisions from the timeframe used to simulate fills and SL/TP.

M5 strategy candle 09:15 -> closes 09:20
                         |
                         v
                 signal becomes known
                         |
                         v
                first eligible M1 open

This avoids lookahead while allowing lower-timeframe execution to resolve intrabar outcomes more accurately.

Causal Timing

A strategy only sees completed strategy candles. The current fixed-timeframe engine determines candle completion from the timeframe duration, then processes the signal before the eligible execution candle opens.

The deterministic execution test proves why this matters: a coarse M5 execution candle can contain both stop and target, while the M1 sequence can reveal which happened first.

Trade Intents

Strategies communicate through a generic executable contract rather than ORB-specific fields.

{
  action: "ENTER",
  side: "LONG",
  stopLoss: { type: "PIPS", value: 10 },
  takeProfit: { type: "PIPS", value: 20 }
}

PRICE levels are also supported. Indicator-specific concepts such as ATR stay inside strategy logic; the engine only receives an executable level.

Execution Model

  • LONG entry: ASK open
  • SHORT entry: BID open
  • LONG stop/target checks: BID low/high
  • SHORT stop/target checks: ASK high/low
  • One open position at a time
  • If SL and TP occur in the same execution candle, stop loss wins conservatively

Results

Completed trades record side, signal/decision time, entry, stop, target, exit, exit reason, PnL in pips and WIN / LOSS / BREAKEVEN. The summary currently reports trade counts, win rate and total PnL in pips.
