Time & Sessions

Timezone Model

Candle timestamps remain UTC. Strategy session logic converts those timestamps into an IANA timezone such as America/New_York. JavaScript's timezone support handles daylight-saving changes automatically.

summer: 12:15 UTC = 08:15 New York
winter: 13:15 UTC = 08:15 New York

Session Windows

src/time/session-window.js classifies a timestamp relative to a configured local session.

{
  startHour: 8,
  startMinute: 15,
  durationMinutes: 60,
  timeZone: "America/New_York"
}

The result is BEFORE, IN_SESSION or AFTER. ORB uses this generic utility rather than embedding timezone calculations in the strategy.

Strategy Candle Timing

The backtest engine treats the timestamp on an OANDA candle as the candle start. A strategy cannot use the final OHLC of an M5 candle stamped 09:15 until that candle has closed at 09:20.

The current runner supports fixed S/M/H timeframes through src/market/timeframe.js. This is deliberately explicit; daily or other variable-session candle semantics should not be faked as a fixed 24-hour duration.

Two Time Series

Strategy and execution timeframes are independent inputs to a backtest job. For example:

strategy:  M5
execution: M1

The strategy still makes decisions only on completed M5 candles, while position entry and protection checks use the M1 sequence.
